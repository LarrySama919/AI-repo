What is a dataset?

A dataset is a collection of examples used by Skinwise features. For example, skin images help evaluate skin-analysis tools, while product reviews support product insights. Validate checks the files and required information; it does not train or change the AI. These dashboard actions are a demo and do not modify source files.

  1. Select a collection
  2. Check its purpose and file type
  3. Run validation and follow up on any issues
